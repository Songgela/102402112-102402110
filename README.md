## 一、项目简介

一个面向校园场景的失物招领信息平台。用户可以：

- 📝 **发布**寻物启事（我丢了东西）与招领启事（我捡到东西）
- 🔍 **浏览 / 搜索**校园里的全部失物招领信息，支持关键词搜索
- 📋 **查看详情**，获取发布者提供的联系方式
- 📞 **一键复制**联系方式，快速联系对方
- ✅ 物品找回或归还后，由发布者**标记状态**为「已找到 / 已归还」，减少重复询问
- 📊 **数据看板**：找回率、近 7 天发布趋势、物品类别分布

### 分层设计说明

项目采用 **数据层 / 视图层 / 入口层** 三层分离的架构：

| 层级 | 文件 | 职责 | 依赖 |
|---|---|---|---|
| 数据层 | `store.js` | 业务逻辑：搜索、筛选、校验、统计、状态流转、持久化 | 无 |
| 数据层 | `data.js` | 静态常量与示例数据 | 无 |
| 视图层 | `views.js` | 数据 → HTML 字符串 | 仅用 store 的工具函数 |
| 入口层 | `app.js` | 路由、事件绑定、编排 | store + views + data |

**为什么要这样分层？**

1. `store.js` 不依赖任何 DOM，因此可以被单元测试直接引入断言，测试时无需启动浏览器；
2. 视图层只做字符串拼接，不碰业务规则，改样式时不会误伤逻辑；
3. 事件全部使用**事件委托**绑定在 document 上，避免列表重渲染后事件失效。

## 三、使用说明（助教老师可以这样操作）

### 方式 A：直接打开网页（推荐，零环境依赖）

1. 下载本项目全部文件到本地任意目录（注意：**要保持目录结构完整**，`css/`、`js/` 等文件夹不能丢）
2. 使用 **谷歌浏览器（Chrome）** 打开根目录下的 `index.html`
   - 也可以右键 `index.html` → 打开方式 → Google Chrome
3. 页面会自动加载 **10 条示例数据**，可直接体验全部功能，无需任何手动录入

> ⚠️ **重要提示**：请务必使用谷歌浏览器，老师发布作业要求统一浏览器以避免不同浏览器下样式差异。
> 本项目**不需要**启动任何本地服务器，也不依赖网络（Mocha/Chai 已下载为本地文件）。

### 方式 B：运行自动化单元测试

**B-1 浏览器方式**

用谷歌浏览器直接打开 `test/test.html`，页面会立即显示测试报告。
全部通过时显示绿色的 **61 passing**。

**B-2 命令行方式**


预期输出：

### 功能操作指南

| 想做什么 | 操作路径 |
|---|---|
| 搜索物品 | 首页顶部搜索框输入关键词（如「校园卡」「图书馆」）→ 回车 |

### 附加特点

1. **一键复制联系方式** —— 手机号自动脱敏（`138****5678`），点击后才展开并复制，兼顾便捷与隐私
2. **数据统计看板** —— 找回率、近 7 天发布趋势柱状图、物品类别分布条形图
3. 多维度组合筛选（类型 + 类别 + 状态 + 关键词）
4. 手机号脱敏保护，防止被批量抓取
5. 表单实时校验与逐字段错误提示，错误信息精确到具体字段
6. 状态可回滚（误标记为已找到后可改回进行中）
7. 纯 CSS 实现的图表与动画，无第三方图表库，加载速度快
8. 首次访问自动注入 10 条示例数据，开箱即可体验完整流程

## 八、常见问题

**松：打开 index.html 后是空白页？**
姜：可能原因：(1) 直接通过网络传输时丢失了 `js/` 目录；(2) 浏览器控制台有报错。
请按 F12 打开控制台查看。另外本项目的 localStorage 数据是**按浏览器+路径**隔离的，
换目录打开会视为全新环境并重新注入示例数据。

**姜：想看无数据的界面？**
松：按 F12 打开控制台，执行 `localStorage.clear()` 后刷新，再执行 `LFApp.renderAll()` 即可看到空状态。

**松：测试页面显示红色失败怎么办？**
姜：展开失败用例查看断言信息。测试用例中已包含详细的中文说明，可以直接定位问题函数。

**姜：为什么手机号默认显示成 `138****5678`？**
松：这是有意设计的隐私保护（见附加特点 1）。点击手机号即可展开完整号码，再次点击会自动复制。
